Basit bir not alma uygulaması. Notes API (ASP.NET Core Web API + Entity Framework Core) ve bu API'yi tüketen bir MVC frontend (ASP.NET Core MVC) içerir.

## Proje Yapısı

## Özellikler

- Not oluşturma, listeleme, görüntüleme, düzenleme ve silme (CRUD)
- API ve frontend'in ayrı katmanlar olarak çalışması
- Bootstrap tabanlı responsive arayüz

## Çalıştırma

1. `MinimalNoteApp` (API) projesini başlatın
2. `MinimalNoteWebMVC` (MVC) projesini başlatın
   - Visual Studio'da "Multiple Startup Projects" ayarlıysa tek F5 yeterli

## Teknolojiler

- ASP.NET Core Web API
- ASP.NET Core MVC
- Entity Framework Core
- Bootstrap 5
